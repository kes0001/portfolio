デザインカンプからサイト制作（ピクセルパーフェクト再現）

プロのデザイナーが作成したFigmaカンプを、ピクセルパーフェクトを目標に再現しました。

Role コーディング
Tools Figma / HTML / SCSS / JavaScript / Swiper
サイトを見る

Purpose制作の目的

プロのデザイナーが作成したFigmaカンプを、正確かつ実践的な手法でWebサイトとして実現する「ピクセルパーフェクトな再現」を最重要目標に掲げました。実務に即した制作工程を経験し、Figmaから要素のサイズ・余白・カラーコードを正確に抽出し、デザイン意図の忠実な再現に努めています。

Codingコーディングについて

効率的で保守性の高い設計を目指し、Sass（SCSS記法）を使用。大規模開発を意識し、スタイルをコンポーネントや役割ごとにファイル分割しました。再利用性・拡張性の高いコードベースのため、BEMに基づく命名規則を徹底しています。

技術的に意識した点・挑戦したことは次のとおりです。

  • 大規模開発を想定し、SCSSをコンポーネント・役割ごとにファイル分割。BEMで命名規則を徹底し、再利用性・拡張性を確保
  • jQueryに頼らず、ドロワーメニュー・アコーディオン・モーダルを素のJavaScriptで実装
  • スライダーはSwiperを採用し、無限ループ（無限スクロール）の設定に挑戦
  • これまで未経験だったフォームの入力値チェック（バリデーション）を新たに実装
  • Figmaからサイズ・余白・カラーコードを正確に抽出し、ピクセルパーフェクトな再現に注力
