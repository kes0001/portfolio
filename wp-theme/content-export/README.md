# 作品コンテンツの書き出し

Local（portfolio-site）のデータベースにある作品12件を、2026-11-19 時点で書き出したものです。
テーマ（`wp-theme/kanzaki/`）には入らない「投稿の中身」の控えです。本番（kanzaki-web.com）も同じ内容です。

| 場所 | 中身 |
| --- | --- |
| `works/<slug>.json` | 題・並び順・抜粋・カテゴリー・カスタムフィールド（`kanzaki_*`）・使っている画像と alt |
| `works/<slug>.html` | 本文（ブロックエディターの生のマークアップ） |
| `uploads/` | アイキャッチと本文中の画像の原本（32枚。WPが自動で作る縮小版は含めていない） |
| `categories.json` | カテゴリーの一覧 |
| `works.xml` | WordPress 標準のエクスポートファイル（ツール → インポート で読める形式） |

## 注意

- 本文中の画像URLは Local のもの（`http://localhost:10009/wp-content/uploads/...`）のままです。別の環境へ戻すときは置き換えが要ります。
- バナー・ロゴ・カンプ制作の本文画像はテーマ側（`kanzaki/assets/images/`）にあるので、`uploads/` には入っていません。
- `local_id` は Local での投稿IDです。本番のIDとは違います。
- 作品を追加・修正したら、この書き出しは古くなります。必要なときに取り直してください。
- 固定ページ・お問い合わせフォームの設定・サイト設定は含みません（トップページの構成はテーマのパターンにあります）。
